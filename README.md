# Рулетка донатов для OBS

Один файл — `index.html`, два виджета из него: карточка сбора «До рулетки» и сама рулетка (горизонтальная, с категориями по редкости и заданиями через запятую). Подключается напрямую к DonationAlerts через их WebSocket (Centrifugo), без стороннего сервера между тобой и донатами — меньше точек, где может порваться соединение.

## 1. Выложи файл на GitHub Pages

Нужен постоянный https-адрес — DonationAlerts не разрешает редирект на `file://` или `localhost`.

1. Зайди на github.com → New repository → назови, например `da-roulette` → Create repository (Public).
2. На странице репозитория: Add file → Upload files → перетащи `index.html` → Commit changes.
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save.
4. Через минуту-две адрес появится там же: `https://<твой-логин>.github.io/da-roulette/`.

## 2. Создай приложение в DonationAlerts

1. Открой `https://www.donationalerts.com/application/clients` → Создать приложение.
2. В поле Redirect URI вставь **ровно ту ссылку**, которую покажет сам виджет (открой свою страницу на GitHub Pages, нажми на шестерёнку ⚙ внизу справа — там в поле «Redirect URI» уже готовая строка, просто скопируй её).
3. Сохрани, скопируй Client ID.

## 3. Настрой виджет

Шестерёнка ⚙ по умолчанию скрыта — чтобы она не попала в кадр на стриме. Для настройки добавь к ссылке `&edit=1`, например `https://<твой-логин>.github.io/da-roulette/?edit=1`, открой в обычном браузере и нажми ⚙:

- вставь Client ID, нажми «Войти через DonationAlerts», авторизуйся;
- задай заголовок карточки сбора (по умолчанию «ДО РУЛЕТКИ»), сумму цели и валюту;
- задай текст над рулеткой (по умолчанию «КРУТИМ КРУТИМ КРУТИМ»), длительность прокрутки, время показа результата и цвет акцента;
- добавляй категории кнопкой «+ добавить категорию»: у каждой — название, уровень редкости и поле с заданиями через запятую. Редкость определяет шанс: значения по умолчанию (Обычная 50, Необычная 25, Редкая 12, Эпическая 6, Легендарная 3, Артефакт 1) можно поменять в блоке «Шансы по редкости» ниже — чем больше число, тем чаще выпадает вся категория целиком. Задания внутри одной категории равновероятны между собой;
- иконкой-глазом в заголовке карточки категория включается/выключается без удаления — выключенная не участвует в розыгрыше, под текстом сразу видно её текущий шанс;
- «Тестовый донат» эмулирует донат на нужную сумму без реальных денег и прогоняет весь цикл целиком (включая передачу сигнала рулетке); «Тестовая прокрутка рулетки» крутит её один раз локально, без доната — удобно для быстрой проверки оформления и шансов.

## 4. Добавь в OBS как два источника

Это два независимых виджета с одной страницы — различаются только параметром `?view=` в ссылке:

- `https://<твой-логин>.github.io/da-roulette/?view=progress` — только карточка «До рулетки», следит за донатами;
- `https://<твой-логин>.github.io/da-roulette/?view=roulette` — только рулетка, невидима и ничего не весит, пока не придёт сигнал о достижении цели.

Добавь оба как отдельные источники: Источники → + → Browser → вставь нужную ссылку → размер под сцену (карточке хватит ~350×120, рулетке — ~800×260) → OK. Расположи их на сцене где удобно — они больше не обязаны находиться в одном месте.

Как только донат доводит сумму до цели, карточка «До рулетки» прячется и отправляет сигнал через общее хранилище браузера, рулетка-источник его подхватывает, плавно появляется, крутится и показывает результат, а карточка возвращается с обнулённым (или перенесённым, если включена соответствующая галочка) прогрессом. Это работает, только если оба источника открыты в OBS одновременно — иначе карточка подождёт сигнала о завершении примерно (время прокрутки + время показа результата + 15 секунд) и сбросится сама, чтобы не зависнуть навсегда.

Если нужно что-то поменять прямо внутри OBS: временно допиши к URL источника `&edit=1` (двойным кликом по полю URL в свойствах источника) → Apply → правой кнопкой по источнику → Interact → жми ⚙, настраивай. Когда закончил — убери `&edit=1` из URL и снова Apply, чтобы шестерёнка не осталась в кадре. Настройки у обоих источников общие — правишь через любой из них.

Хочешь один совмещённый виджет вместо двух — используй ссылку без `?view=` (просто `index.html`, при настройке `?edit=1`), это старый режим «всё на одной странице», без обмена сигналами между источниками.

## Перенос настроек между браузером и OBS

localStorage не общий между обычным Chrome и встроенным браузером OBS — это два разных профиля. Если настраивал в Chrome, а используешь в OBS (или наоборот):

1. В настройках, где всё уже готово, — «Экспорт» → скопируй текст.
2. На другой стороне (через Interact, если это OBS) — вставь текст в то же поле → «Импорт».

Экспорт включает токен входа, так что после импорта логиниться второй раз не нужно. Эту строку никому не показывай и не выкладывай — по сути это доступ к твоему аккаунту DonationAlerts.

Между двумя источниками **внутри одного OBS** (карточка и рулетка) этот перенос обычно не нужен — у них общий браузерный профиль, поэтому настройки и сигнал о донате доходят от одного к другому сами. Если в твоей версии OBS это почему-то не так (карточка прячется, а рулетка не реагирует) — тот же способ экспорт/импорт чинит и это, либо просто пересобери оба источника на ссылку без `?view=` (один совмещённый виджет, раздел 3 выше).

## О надёжности соединения

Виджет сам переподключается при обрыве (с нарастающей паузой между попытками) и держит статус-индикатор в левом верхнем углу — включается чекбоксом «Показывать статус соединения» в настройках: зелёная точка — всё работает, жёлтая — идёт подключение, красная — не подключено (например, истёк токен — тогда помогает только повторный вход через ⚙).

Все обращения идут напрямую на `donationalerts.com` и `centrifugo.donationalerts.com` — если у тебя не грузятся именно эти домены без VPN, виджет будет обрываться по той же причине, что и родная рулетка: это ограничение на стороне сети/провайдера, а не что-то, что лечится в коде страницы.
