# Бот Сонечки для Twitch-чата

Отдельный процесс, который сидит в чате и:
- на команду `!ловлю` засчитывает 1 литр молочка тому, кто написал (пока не кончились литры в текущем раунде заливки);
- на команду `!молочко` отвечает, сколько литров молочка на балансе у написавшего.

Сам баланс и раунды ловли хранятся на бэкенде (`api/catch.js` в этом репозитории, тот же Vercel-проект и Upstash Redis, что и для остальной статистики) — бот ничего не хранит сам, только слушает чат и дёргает API.

## 1. Создать Twitch-аккаунт для бота

Если ещё нет — заведите отдельный Twitch-аккаунт (например `sonechka_bot`). Писать от своего основного аккаунта тоже можно, но для бота он не нужен, и общепринято заводить отдельный.

## 2. Получить OAuth-токен бота

Токен нужен именно для **аккаунта бота** (войдите под ним), со скоупами на чтение/запись чата. Проще всего через generator, которым пользуется большинство Twitch-ботов на tmi.js:

1. Откройте https://twitchtokengenerator.com
2. Выберите "Bot Chat Token" (или вручную отметьте скоупы `chat:read` и `chat:edit`)
3. Войдите под аккаунтом **бота**, разрешите доступ
4. Скопируйте токен вида `oauth:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — это `TWITCH_BOT_OAUTH_TOKEN`

## 3. Придумать секрет и добавить его в Vercel

Нужна любая случайная строка (секрет), которой бот будет подтверждать серверу, что именно он (а не кто попало) засчитывает литры.

1. Придумайте длинную случайную строку, например через `openssl rand -hex 32` или просто набор случайных символов
2. В Vercel-проекте (`da-roulette`) → Settings → Environment Variables добавьте переменную `CATCH_SECRET` с этим значением
3. Передеплойте проект (любой новый коммит/push, либо Redeploy в Vercel), чтобы переменная подхватилась

## 4. Задеплоить бота в облако (Railway)

1. Зайдите на https://railway.app, войдите (можно через GitHub)
2. New Project → Deploy from GitHub repo → выберите этот репозиторий (`da-roulette`)
3. В настройках сервиса укажите **Root Directory** = `bot` (чтобы Railway собирал именно папку бота, а не весь репозиторий)
4. В Variables добавьте:
   - `TWITCH_BOT_USERNAME` — имя аккаунта бота
   - `TWITCH_BOT_OAUTH_TOKEN` — токен из шага 2 (вместе с `oauth:` в начале)
   - `TWITCH_CHANNEL` — имя вашего канала (без @ и без twitch.tv/)
   - `CATCH_API_URL` — `https://da-roulette.vercel.app/api/catch`
   - `CATCH_SECRET` — та же строка, что в шаге 3
   - (необязательно) `CATCH_COMMAND` / `BALANCE_COMMAND`, если хотите другие команды вместо `!ловлю` / `!молочко` — тогда те же значения поставьте и в настройках виджета Сонечки
5. Deploy. В логах должно появиться `connected to ..., joined #ваш_канал`

## Важно

- Команда ловли (`!ловлю`) и окно по времени (сколько секунд ловим) должны совпадать в виджете (настройки Сонечки → «Ловля молока») и в боте (`CATCH_COMMAND`) — иначе бот будет слушать не ту команду, или окно виджета истечёт раньше, чем бот перестанет засчитывать.
- Бот **не отвечает в чат на каждую пойманную дойку** (10 литров за несколько секунд — иначе зальёт чат сообщениями). Результат виден на экране трансляции. `!молочко` отвечает всегда.
- `.env` никогда не коммитьте в репозиторий — он уже в `.gitignore`. В Railway используйте Variables в интерфейсе.
